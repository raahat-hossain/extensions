R2 Library JSON

One details.json with a chapters array. Drop it in the series folder. Split files still work.

Series

Cover: Chapter 1_1 = first page of the chapter titled Chapter 1. Or a direct image URL.

Chapters

Folder/cbz chapters already in the series stay. Same number replaces that chapter (e.g. swap ch.4). Higher numbers append (6, 7 after 5). MangaDex/NovelCrow page URLs are not readable — use a gallery / cbz / folder URL.

Blank name becomes Chapter N. Turn overlay off only if you want JSON chapters listed in addition to the same-numbered folder/cbz.
